# 橙光队无障碍督导标准查询

> 南方科技大学致诚书院"橙光"志愿服务队的无障碍督导标准在线查询工具，供志愿队员在督导活动中实时查阅标准条文。

## 收录标准

| 标准 | 标准号 | 性质 |
|------|--------|------|
| 建筑与市政工程无障碍通用规范 | GB 55019-2021 | 全文强制性 |
| 无障碍设计规范 | GB 50763-2012 | 部分强制 |
| 无障碍设计标准 | SJG 103-2021 | 地方标准（深圳） |

## 功能

- **关键词搜索**：输入关键词即时搜索所有标准条文，支持多关键词空格分词、条文编号、正文、章节名称搜索
- **常见问题速查**：14 个常见无障碍问题分类展示，点击展开查看关联标准原文
- **标准大纲**：可展开/折叠的树形结构浏览所有标准条文，展开状态自动记忆
- **PDF 查看器**：内置 PDF 查看器，支持缩放、旋转、页码跳转
