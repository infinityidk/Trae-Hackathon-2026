# 贡献指南

感谢你对本项目的关注！我们欢迎各种形式的贡献，包括功能开发、Bug 修复、文档改进和代码优化。

## 🚀 快速开始

1. Fork 本仓库
2. 克隆你的 Fork 到本地：
   ```bash
   git clone https://github.com/your-username/survey-map.git
   cd survey-map
   ```
3. 安装依赖：
   ```bash
   npm install
   ```

## 🌿 分支规范

- 新功能：`feature/功能描述`
- Bug 修复：`fix/问题描述`
- 文档更新：`docs/文档描述`

## 📝 提交规范

提交信息应清晰描述变更内容，建议使用以下前缀：

- `feat:` 新功能
- `fix:` 修复问题
- `docs:` 文档更新
- `style:` 代码格式调整（不影响功能）
- `refactor:` 代码重构
- `perf:` 性能优化
- `chore:` 构建过程或辅助工具的变动

示例：
```bash
git commit -m "feat: 添加线路搜索功能"
git commit -m "fix: 修复移动端统计面板显示异常"
```

## 🧪 开发注意事项

- 保持代码风格与现有代码一致
- 确保修改不会破坏现有功能
- 本地测试通过后再提交

## 📬 提交 Pull Request

1. 推送分支到 Fork 仓库：
   ```bash
   git push origin feature/your-feature
   ```
2. 在原仓库页面点击 "New Pull Request"
3. 填写 PR 标题和描述，说明变更内容和动机
4. 等待维护者审核

## 🐛 报告问题

发现 Bug 或有功能建议，请在 GitHub Issues 中创建新 Issue，并尽可能提供以下信息：

- 问题描述
- 复现步骤
- 预期行为与实际行为
- 浏览器及操作系统环境
- 相关截图（如有）
